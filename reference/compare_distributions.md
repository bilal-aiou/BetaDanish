# Compare Beta-Danish with Standard Distributions

Fits standard lifetime distributions (Weibull, Log-Normal, Log-Logistic,
Gamma, Exponential) using the \`flexsurv\` package and compares them to
the Beta-Danish fit.

## Usage

``` r
compare_distributions(object)
```

## Arguments

- object:

  A fitted \`betadanish\` object.

## Value

A ranked data frame of model comparisons.
